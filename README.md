# Node CLI Projects

This repository contains small command-line applications built using **Node.js** while learning backend development fundamentals.

## Projects Included

### 1. Task Tracker

A CLI application to manage tasks directly from the terminal.

**Features**

* Add new tasks
* Update task status
* Delete tasks
* List all tasks
* Persist tasks using JSON storage

### 2. Number Guessing Game

A simple command-line game where the user tries to guess a randomly generated number.

**Features**

* Random number generation
* User input from terminal
* Feedback for incorrect guesses
* Game loop until correct guess

## Tech Stack

* Node.js
* JavaScript
* File system (`fs`) module for data storage

## How to Run

Clone the repository:

```
git clone https://github.com/BadriSatwik/node-cli-projects.git
cd node-cli-projects
```

Run a project:

```
node task-tracker/index.js
```

or

```
node number-guessing-game/index.js
```

These projects were built to practice:
